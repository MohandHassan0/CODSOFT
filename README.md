
# CodSoft Internship Projects

This repository contains a collection of beginner to intermediate-level C++ projects completed as part of a one-month internship with **CodSoft**. Each project demonstrates a different concept, from basic I/O and control flow to file handling and simple logic-based games.

## 📂 Projects Included

### ✅ To-Do List
A simple command-line application that allows users to:
- Add tasks
- View tasks
- Mark tasks as completed  
Uses basic file handling to store task data persistently.

### 🎮 Tic-Tac-Toe
A classic two-player tic-tac-toe game built with C++.
- Console-based interface  
- Turn-based logic  
- Win/draw detection

### 🔢 Number Guessing Game
- Random number generator with user attempts  
- Feedback on guesses (too high/low)  
- Tracks the number of attempts

### 🧮 Calculator
A basic calculator that performs:
- Addition, subtraction, multiplication, and division  
- Input validation and continuous operation

## 💡 What I Learned
- Fundamentals of **C++ programming**
- Working with **functions**, **loops**, and **conditions**
- File operations and data storage
- Structuring small projects for clarity and reusability

## 🛠️ Technologies
- C++
- Command-line interface (CLI)
